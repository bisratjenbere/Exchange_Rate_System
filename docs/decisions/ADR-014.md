# ADR-014 — Freshness thresholds per source

Status: PENDING (requires 14 days of live data)
Date: 2026-10-12
Deciders: owner + agent

---

## Context

The trusted view currently flags a rate as STALE when:

    fetched_at::date - effective_date > 3 days

This threshold (3 days) is a placeholder from gap review §21. It was chosen
conservatively to avoid false positives during early collection. It has not
been validated against actual bank publication patterns.

Phase 8 requires measuring real publication cadence before setting permanent
thresholds. This ADR is the home for that decision.

---

## What needs to be measured (after 14 days of data)

For each enabled source, query:

```sql
SELECT
    rs.bank_id,
    rs.adapter_key,
    COUNT(DISTINCT o.effective_date)            AS distinct_dates,
    MIN(o.effective_date)                       AS earliest,
    MAX(o.effective_date)                       AS latest,
    AVG(
        EXTRACT(EPOCH FROM (
            LEAD(o.effective_date::timestamp) OVER (
                PARTITION BY o.source_id ORDER BY o.effective_date
            ) - o.effective_date::timestamp
        )) / 86400
    )                                           AS avg_days_between_publications
FROM rate_observation o
JOIN rate_source rs ON rs.id = o.source_id
WHERE o.identity_status = 'confirmed'
  AND o.is_current = TRUE
GROUP BY rs.bank_id, rs.adapter_key
ORDER BY rs.bank_id;
```

Expected findings:
- Daily publishers (CBE, Dashen, Rammis, Wegagen): threshold = 2 days
- Weekly or irregular publishers: threshold = 8 days
- Sources with no pattern yet: keep 3-day placeholder, review at 30 days

## Decision criteria

A threshold is CONFIRMED when:
1. At least 14 consecutive days of CONFIRMED observations exist for that source.
2. The measured avg_days_between_publications is stable (stddev < 1 day).
3. The proposed threshold = ceil(avg) + 1 day buffer.

A threshold remains PENDING if fewer than 14 days of data exist.

## What does NOT change

- The staleness flag is display-only. It never suppresses a rate from the
  trusted view. LOCKED rule: never silently substitute an older rate.
- Thresholds are per-source, not global. A slow-publishing bank must not
  trigger alerts designed for daily publishers.
