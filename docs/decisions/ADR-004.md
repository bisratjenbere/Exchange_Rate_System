# ADR-004: CBE API accepted as authoritative official source

Date: 2026-10-10
Status: APPROVED (owner decision)

## Decision
The CBE API at https://combanketh.et/cbeapi/daily-exchange-rates/ is accepted as the authoritative official source for CBE exchange rates. A browser-rendered comparison of API values against the official display page is not required before the adapter is built.

## Reason
The API is hosted on CBE's own domain (combanketh.et). The official exchange-rates page (combanketh.et/exchange-rates) is JavaScript-rendered and uses this same API as its backend. The owner confirmed this ruling explicitly.

## Consequence
The CBE mapping verification_status may advance to `verified` after field-level checks are complete, without a separate browser-rendered visual comparison. The API values are treated as the official publication.
